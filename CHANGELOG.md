## [1.0.0] — 2026-06-15

### Added

Initial release. Nine globally installed Claude Code skills:

#### Design

- **`banner-design`** — multi-format banner generation for social media, ads, web heroes, and print. 12 art styles, AI-generated visuals, covers all major platforms (Facebook, Twitter/X, LinkedIn, YouTube, Instagram, Google Display).

- **`design`** — unified design skill combining brand identity, design tokens, UI styling, logo generation (55 styles via Gemini AI), corporate identity programs (50 deliverables with mockups), HTML presentations, banner design (22 styles), icon design (15 SVG styles), and social photos across all major platforms.

- **`design-system`** — three-layer design token architecture (primitive → semantic → component), CSS variable systems, spacing and typography scales, component state specifications, and strategic HTML slide generation with Chart.js.

- **`ui-styling`** — accessible UI component skill using shadcn/ui (Radix UI + Tailwind), Tailwind CSS utilities, canvas-based visual design, dark mode, responsive layouts, and a curated set of 27 bundled web fonts.

- **`ui-ux-pro-max`** — comprehensive UI/UX design intelligence across 10 technology stacks (React, Next.js, Vue, Svelte, SwiftUI, React Native, Flutter, Tailwind, shadcn/ui, HTML/CSS). Includes 50+ design styles, 161 color palettes, 57 font pairings, 161 product types, 99 UX guidelines, and 25 chart types.

#### Brand

- **`brand`** — brand voice definition, visual identity standards, messaging frameworks, asset management, consistency auditing, and style guide development.

#### Presentations

- **`slides`** — strategic HTML presentation design with Chart.js data visualization, design tokens, responsive layouts, copywriting formulas, and contextual slide strategies.

#### Writing

- **`stop-slop`** — removes predictable AI writing patterns from prose (filler phrases, formulaic structures, passive voice). By [Hardik Pandya](https://hvpandya.com).

#### Decision Making

- **`llm-council`** — runs questions and decisions through 5 independent AI advisors with different analytical lenses, anonymous peer review, and synthesized verdict. Adapted from Andrej Karpathy's LLM Council methodology.
